# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be civil. Technical disagreement is the point of a code review and is welcome; personal attacks, harassment and demeaning comments are not, and neither is bringing an argument from somewhere else into this repo.

## Enforcement

Report unacceptable behaviour privately to overby999@gmail.com. Reports are read by the maintainer, Aleksey Malyuta (@utftu), and stay between the people involved. The maintainer may delete comments, close threads or block accounts, and will say which rule was broken when doing so.
