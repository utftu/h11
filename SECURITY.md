# Security policy

## Supported versions

Only the latest published version of each package is supported. Fixes go out as a new patch release; older versions receive nothing, so updating is the upgrade path.

| Package | Supported            |
| ------- | -------------------- |
| `h11`   | latest release only  |
| `h11-x` | latest release only  |

## Reporting a vulnerability

Report privately — not through a public issue:

- [GitHub Security Advisories](https://github.com/utftu/h11/security/advisories/new) — preferred;
- or email overby999@gmail.com.

Please include the package and version, what an attacker gains, and the shortest reproduction you have.

You get a first response within 7 days. If the report is confirmed, you will be told when the fix is released; if it is not, you will be told why.

Please do not disclose publicly until a fixed version is out.
