# h11

Монорепозиторий с самописным HTTP-стеком на Bun/TypeScript: минималистичный роутер с раздачей статики и провайдерами рантайма (`h11`), и SSR-надстройка поверх Vite + [regan](https://www.npmjs.com/package/regan) (`h11-x`).

## Пакеты

| Пакет | Что делает |
|---|---|
| [`packages/h11`](./packages/h11) | Ядро — класс `H11` с radix-роутером, middleware, обработкой ошибок, раздачей статики; `h11/bun`, `h11/node` — провайдеры для запуска под Bun/Node |
| [`packages/h11-x`](./packages/h11-x) | SSR/гидрация поверх `h11` + Vite + regan |
| [`packages/h11-x-example`](./packages/h11-x-example) | Рабочий пример, связывающий всё вместе |

## Разработка

```bash
bun install
bun test    # тесты всех пакетов
```

Каждый пакет собирается независимо:

```bash
cd packages/h11 && bun run build && bun run types
```

Либо через оркестратор задач [`dapes`](https://www.npmjs.com/package/dapes), который знает о зависимостях между пакетами (`h11` → `h11-x` → `h11-x-example`):

```bash
bun run dapes.run.ts x build        # соберёт h11 → h11-x по цепочке
bun run dapes.run.ts example run    # поднимет пример на :3000
```

## Релиз в npm

Публикация — по тегу, вручную, никакой автоматики на каждый пуш:

1. Бампнуть версию в `packages/<pkg>/package.json`, закоммитить как обычное изменение.
2. `bun run release <pkg>` — сам прочитает версию из `package.json`, покажет тег и спросит подтверждение перед `git tag` + `git push` (версию печатать руками не нужно).
3. [`.github/workflows/publish.yml`](./.github/workflows/publish.yml) подхватывает тег, сверяет версию с `package.json`, гоняет тесты по всему монорепозиторию, собирает и публикует именно тот пакет, что в теге.

Если версия в теге не совпадает с `package.json` — воркфлоу падает до публикации, ничего не уходит в npm. Требует секрет `NPM_TOKEN` в настройках репозитория.

Это отдельный, более простой путь, чем `bun run dapes.run.ts <pkg> publish` — та dapes-команда сама делает `git push` + бамп версии + тег + `git push` тега, то есть весь ручной шаг 1–2 автоматизирует под себя. Использовать что-то одно: либо тег руками → CI публикует, либо dapes-таск целиком со своей машины.

## Статус

Личный/экспериментальный проект. `h11` покрыт тестами и относительно устоялся; `h11-x` — активно меняющийся SSR-слой (версия `0.0.x`), API может измениться без предупреждения.
